# Impostor Night

A free, offline, pass-the-phone party word game. Everyone gets the secret word except the impostor. Give one-word clues, vote out the sus one, and keep score across episodes.

- 3D hold-to-reveal cards, one per player
- Word packs: Anime Series, Anime Characters, Anime Tropes, Gen Z Slang, Internet & Memes, Gen Z Life, Games, Spicy (18+), plus your own words
- Classic and Undercover modes, multiple impostors, Chaos mode, last-chance word steal, timer, leaderboard

It's a single static file: open `index.html` in a browser, or serve the folder with any static host.
